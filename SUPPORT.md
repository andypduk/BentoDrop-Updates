# BentoDrop support

BentoDrop is an independent macOS app for the 1010 Music Bento. It is not an official 1010music product.

- [Read the help guide](docs/Help.md) for setup, sample transfers, card backups, and firmware preparation.
- [Troubleshoot a problem](docs/Help.md#troubleshooting) before opening an issue.
- [Download the latest release](https://github.com/andypduk/BentoDrop-Updates/releases/latest), or choose **Bento Drop → Check for Updates…** in the app.
- [Report a bug or request a feature](https://github.com/andypduk/BentoDrop-Updates/issues/new). For firmware running on the device or hardware faults, contact [1010music Support](https://1010music.com/support).

When reporting a bug, include your BentoDrop and macOS versions, what you tried, what you expected, and the exact error. For sample transfers, include the file format and duration. You can export the affected job's log with **Save Log…**. GitHub issues are public, so remove personal paths or filenames before sharing a log.
